## About This Handbook

This handbook is for students and developers who are new to AWS. It walks you through creating your first AWS account, understanding core cloud concepts, learning about the AWS SBG DBIT community, and navigating the AWS certification landscape.

Maintained by the **AWS Student Builder Group (SBG) at DBIT** in collaboration with the Department of AI & ML, Don Bosco Institute of Technology, Bengaluru.

## Chapter Summaries

### Chapter 1 — Creation of AWS Account
8-step account creation process with a link to the [detailed visual guide (Google Doc)](https://docs.google.com/document/d/1NL0-PokC71mwcqYCLNTaYR3wPRFTk5X9LuXGrsQhzSk/edit?usp=sharing). Covers prerequisites, MFA setup, creating an IAM admin user, and setting up a billing alert.

### Chapter 2 — AWS & Cloud Basics
Covers the problems with traditional IT before cloud, what cloud computing is, a brief AWS history timeline from 2006 to today, AWS global infrastructure (Regions, AZs, Edge Locations), and an AWS service quick reference table.

### Chapter 3 — AWS SBG DBIT
What AWS Student Builder Group is, what the club does (workshops, hackathons, certification guidance, community building), AfterHours meetup series, and all social media handles.

### Chapter 4 — Certifications & Resources
Full AWS certification roadmap from Foundational to Professional. Includes a simple certification details table, cert paths for AIML students and other roles, AWS Builder Center free voucher guide, Skill Builder learning paths from beginner to expert, exam prep tips, and other recommended resources.
